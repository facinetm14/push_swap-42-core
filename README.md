# Push Swap

Sort a sequence of integers using two stacks and a restricted set of operations. The [sorting logic](ft_sort.c) chooses operations, while [rotation](ft_rotate.c) and [swap](ft_swap_both_top.c) implement individual moves.

Build with `make`. Try a short, unsorted sequence such as `./push_swap 3 1 2` and follow the emitted operations on paper.
